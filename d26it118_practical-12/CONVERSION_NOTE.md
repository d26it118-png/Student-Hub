# Practical 11 → Practical 12 conversion

This project retains the StudentHub site, authentication and MySQLi connection from Practical 11 and adds an admin-only Event Management module with poster uploads and server-side file validation.

- Main module: `Pages/event_management.php`
- Database migration/sample records: `db/practical12_event_management.sql`
- Test cases: `docs/PRACTICAL12_TEST_CASES.md`
- Upload destination: `uploads/event_posters/`
- Admin Dashboard now links to Event Management.

Import the Practical 12 SQL script once into the existing `studenthub` database. Read `README_PRACTICAL12.md` for setup details.
